# Панель 15 — Электрозадвижки, 8 шт. (без положения)

Точки подключения внешнего оборудования. Файл читает генератор библиотеки,
поэтому **таблица ниже — данные**: заголовки столбцов менять нельзя.
Формат — [Каналы подключения.md](../Каналы%20подключения.md).

Панель обслуживает **восемь электроприводов запорной арматуры** без указателя
положения. На каждый привод — блок фасада 60 мм: четыре лампы
(«Закрыто / Открыто / Готов / Отк-зак») и два переключателя
(«Мест / Откл / Авто» и «Закр / Откл / Откр»).

Источник: `+15`, спецификация `СО_16`/`СО_23`/`СО_24` (31 позиция), схемы
`С3_2`…`С3_9` — по листу на привод. Модули ПЛК: `A1` CN-8032-L, `DI1`, `DI2`
CT-121F (по 16 DI), `DO1`, `DO2` CT-2718 (по 8 DO реле), `TM1` CT-5801. Реле
`1KL1`…`8KL2` — по два на привод.

Состав сигналов одного привода по листам `С3_2`…`С3_9`: концевые выключатели
«закрыт» и «открыт» (по паре контактов Н/З и Н/О), «управление местное» и
«управление авто» — четыре дискретных входа; команды на пускатели `KM1`, `KM2`
через реле `nKL1`, `nKL2` — два дискретных выхода. Питание привода — кабель
ВВГнг-LS 5×1,5 (3~ + PE), в каналы ПЛК не входит.

Итог: 32 DI из 32 и 16 DO из 16 — дискретный ввод и вывод заняты полностью.

## Что взято из схем и что не заполнено

1. **Раскладка по каналам ПЛК прочитана со схем**: листы `С3_2`…`С3_5` — приводы
   1…4 на модулях `DI1`/`DO1`, листы `С3_6`…`С3_9` — приводы 5…8 на `DI2`/`DO2`.
   Карты ПЛК (`СО_17.1`…`СО_17.3`) пустые: заполнен только столбец «Канал».
2. **Взрывозащита `Exd`** — по маркировке привода `КШФЗ с HQ-010-IIBT4` на всех
   восьми листах: цепи идут к взрывозащищённому приводу, барьеров в панели нет.
3. **Номера контактов клемм** не заданы: клеммники двухъярусные UKK 3
   (`1XT1`…`8XT2`, 48 шт., по шесть на привод), раскладка цепей по контактам в
   разобранных листах не читается.
4. **Спецификация панели в выгрузке съехала** (замечание 12): листы `СО_14`/`СО_15`
   папки `+15` содержат состав панели 65, поэтому состав взят со страниц прошлой
   выгрузки `СО_16`, `СО_23`, `СО_24`.

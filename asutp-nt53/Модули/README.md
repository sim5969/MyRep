# Фотографии модулей

Папка для исходных фотографий лицевых панелей модулей.

## Именование файлов

```
<код> <наименование>.jpg
```
01 Панель слота 1.jpg
04 Панель управления электродвигателями с прямым пуском, 4шт.jpg
03 Электрозадвижки регулирующие, 4шт .jpg
05 Панель установки приборов ГАММА-8М, 4шт.jpg
15 Панель электрозадвижек, 8шт.jpg
45 Панель управления чакстотными преобразователями, 4шт.jpg
65 Панель управления чакстотными преобразователями, 4шт и электрозадвижками, 2шт.jpg

Примеры:

```
02 Панель с индикаторами 8 шт.jpg
45 Панель управления задвижками.jpg
47 Панель уровнемеров.png
```

- код — двузначный, как в обозначении шкафа `НТ53.AA.BB.CC.DD`;
- наименование — как в спецификации, без символов `\ / : * ? " < > |`;
- если фотографий на один модуль несколько, добавлять суффикс: `02 Панель с индикаторами 8 шт (2).jpg`.

По этим фотографиям собираются JSON-описания панелей в `src/library/`.
Проверка геометрии после правки: `node scripts/check-library.mjs`.

# AI project context

## Организация-исполнитель

**ООО «Нефтяные технологии»** (ООО «НТ»). Реквизиты и фирменное оформление —
`AI/company/Реквизиты_ООО_НТ.md`.

## Проект

**Шифр:** НТ53
**Наименование:** Конфигуратор внешнего вида секций АСУ ТП
**Тип:** программный проект (веб-приложение Vite + TypeScript + React)
**Репозиторий:** `NT/asutp-nt53` (Gitea, `http://NT1:3000`)

Приложение собирает фасад секции АСУ ТП из типовых вставных модулей (лицевых панелей),
раскладывает приборы и шильды по слотам и выгружает комплект документов: альбом PDF А3 в
фирменной рамке ООО «НТ», DXF вида на фасад, таблицу надписей (CSV) и спецификацию (XLSX).
Библиотека модулей собирается по рабочей документации EPLAN и фотографиям панелей.

Проектная папка (локальная Git-копия):

```text
C:\NT\Шкафы АСУТП НТ53
```

Бинарники и выгрузка EPLAN — на Synology `P:\Projects\Шкафы АСУТП НТ53` (в Git не ведутся).

## Назначение AI-пакета

Каталог `AI/` хранит общий контекст для совместной работы по всем направлениям проекта: куда
смотреть новому участнику, какие файлы актуальны, какие операции опасны, какие решения приняты,
реквизиты и оформление ООО «НТ» (`AI/company/`).

Техническое устройство приложения (геометрия секций, формат записи модуля, порядок выгрузок,
как добавить панель) описано в **корневом `README.md`** — он и есть профильный контекст по коду.

## Текущие основные направления

### 1. Библиотека модулей (панелей)

Состав и коды панелей — по фотографиям в папке `Модули` (в Git) и выгрузке EPLAN. Панели
**генерируются** из `scripts/gen-library.mjs` в `src/library/*.json`; каналы подключения —
`docs/каналы/<код>.md`. Порядок: правка генератора → `npm run gen:library` → `npm run check`.
Разбор выгрузки EPLAN — `scripts/rd-facade.mjs`, `scripts/rd-spec.mjs`.

Рабочие файлы:

```text
scripts/gen-library.mjs          генератор библиотеки
src/library/*.json               сгенерированные описания панелей
docs/каналы/<код>.md             каналы подключения (заполняет инженер)
docs/Рабочая документация — данные панелей.md
```

### 2. Выгрузки (PDF / DXF / надписи / спецификация)

Модули выгрузки в `src/export/`. Фирменная рамка А3 генерируется из шаблона AI-пакета ООО «НТ»
(`npm run gen:frame`). Проверки — `npm run check:pdf`, `npm run check:dxf`.

### 3. Предварительная компоновка по ТЗ

`scripts/plan.mjs` раскладывает объекты автоматизации по модулям и секциям; `scripts/export.mjs`
выгружает документы из командной строки. Правило «объект ТЗ → модуль» — `scripts/kinds.mjs`.
Эти же скрипты вызывает плагин-навык `asutp-sections` (маркетплейс `nt-tools`).

## Как добавлять новые направления

1. Добавить подраздел `### N. …` в «Текущие основные направления» выше.
2. При необходимости создать `AI/context/<short_topic>_context.md`
   (шаблон — `AI/context/_template_section_context.md`).
3. Отразить в `PROJECT_MANIFEST.md`.

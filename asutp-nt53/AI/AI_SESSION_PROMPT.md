# Стартовый контекст AI-сессии — ООО «Нефтяные технологии»

Используй этот файл как краткий стартовый контекст для новой сессии.

## Организация-исполнитель

Документы выпускаются от имени **ООО «Нефтяные технологии»**. Реквизиты и логотип —
`AI/company/Реквизиты_ООО_НТ.md`. Реквизиты вручную из памяти не вводить.

## Рабочая папка

Работай только внутри проектной папки:

```text
C:\NT\Шкафы АСУТП НТ53
```

## Обязательные файлы перед началом

Сначала прочитай:

```text
AI/README.md
AI/AI_PROJECT_CONTEXT.md
AI/AI_RULES.md
AI/AI_HANDOFF.md
AI/PROJECT_MANIFEST.md
AI/DECISIONS.md
```

Если задача связана с конкретным направлением, дополнительно прочитай профильный контекст:

```text
AI/context/[short_topic]_context.md
```

## Главные ограничения

- Не выходить за пределы проектной папки.
- Не запускать обработку, изменяющую файлы, без явной команды пользователя.
- Не менять файлы, если пользователь просит только анализ или план.
- Не затирать ручные колонки, ручные значения и примечания.
- Не изменять производные/формульные колонки вручную.
- Перед массовой записью делать резервную копию в `AI/backups/`.
- Документы оформлять с реквизитами ООО «НТ» из `AI/company/`.

## Как отвечать

Если задача не требует записи в файлы, сначала дать анализ и предложение. Если задача требует
записи, кратко объяснить, что будет изменено, и выполнять только в рамках запроса пользователя.

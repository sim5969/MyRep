# scripts/

Скрипты обработки и анализа данных проекта (Python/PowerShell).

Соглашение об именовании:

- `_analyze_*.py`, `_inspect_*.py` — анализ и проверка, **не меняют** файлы; запускать свободно.
- `_classify_*.py`, `_fill_*.py`, `_add_*.py`, `_rebuild_*.py`, `_export_*.py` — **изменяют**
  файлы или создают выгрузки; запускать только после явного разрешения пользователя.

Скрипты читают рабочие файлы проекта; резервные копии пишут в `AI/backups/`, отчёты — в
`AI/reports/`. На сетевых дисках использовать PowerShell, а не Bash.

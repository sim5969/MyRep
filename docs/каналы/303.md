# Панель 303 — Электрозадвижки регулирующие, 3 шт.

Точки подключения внешнего оборудования. Файл читает генератор библиотеки,
поэтому **таблица ниже — данные**: заголовки столбцов менять нельзя.
Формат — [Каналы подключения.md](../Каналы%20подключения.md).

Панель — исполнение панели 03 на **три электропривода регулирующей арматуры**.
На каждый привод — свой блок фасада: индикатор ТРМ1 положения, четыре лампы
(«Закрыто / Закрыть / Открыть / Открыто») и два переключателя
(«Мест. / Откл. / Авт.» и «Закрыть / Открыть»).

Источник: **рабочей документации на панель нет** (замечание 42), панель описана
по фотографии. Каналы заполнены по аналогии с панелью 03 (`+03`, схемы
`Э3_1`…`Э3_5`): тот же состав сигналов на привод, те же модули ПЛК `A1`
CN-8032-L, `AI1` CT-3238 (8 AI), `DI1` CT-121F (16 DI), `DO1` CT-2738 (8 DO реле),
`TM1` CT-5801; реле `KL1`…`KL6` (Finder 40.52) — по два на привод. Третьего
привода на снимке нет (блок «Резерв» без индикатора), но вырез и обвязка под
него есть — канал ЗД3 оставлен.

Состав сигналов одного привода — как у панели 03 (лист `Э3_2`, блок `=11`):
указатель положения 4…20 мА заходит на ТРМ1 (`In+`), его ретрансляция (`O+`)
идёт на модуль `AI1`; четыре дискретных входа — «закрыто», «открыто», «автомат»,
«отключен»; две команды «закрыть» и «открыть» через реле.

Итог: 3 AI из 8, 12 DI из 16, 6 DO из 8. Трёх приводов хватает на один модуль
`DI1` и один модуль `DO1` — второй модуль дискретного вывода панели 03 здесь
не нужен.

## Что не заполнено и почему

1. **Все данные — по аналогии с панелью 03, а не по документации.** Состав
   модулей ПЛК, клеммы и привязка каналов к модулям приняты как у 03 и требуют
   подтверждения выгрузкой панели 303 (замечание 42).
2. **Номера контактов клемм** не заданы: раскладки цепей по контактам нет даже
   у панели 03.
3. **Взрывозащита не указана.** Как у панели 03: барьеров и маркировки
   взрывозащищённого привода в источнике нет, поэтому поле пустое, а не `нет`.
4. **Артикул лицевой панели** не присвоен: панель в проекте EPLAN отсутствует.

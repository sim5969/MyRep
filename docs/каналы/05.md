# Панель 05 — Уровнемеры ГАММА-8М, 4 шт.

Точки подключения внешнего оборудования. Файл читает генератор библиотеки,
поэтому **таблица ниже — данные**: заголовки столбцов менять нельзя.
Формат — [Каналы подключения.md](../Каналы%20подключения.md).

Панель несёт **четыре контроллера ГАММА-8М** (ЗАО «Альбатрос»), у каждого
**два канала измерения** — значит восемь точек уровня, восемь объектов модуля.
Датчик уровня подключается не к клеммам ПЛК, а к самому прибору: жгутом
УНКР.685622.008 с вилкой DB-15M. Наружу прибор отдаёт данные по RS-485
(`DATA+`/`DATA−`/`SGND`, вилка DB-9M) — по одной линии на прибор.

Источник: `+05`, схема `С3_23`, лист компоновки `СБ_21`. Групповой спецификации
именно этой панели в выгрузке нет (`СО_24`/`СО_25` относятся к другой позиции),
модулей ПЛК в схеме нет — RS-485 уходит на «ЭВМ верхнего уровня».

## Что не заполнено и почему

1. **Сводка сигналов пустая, и это не пробел в данных, а свойство панели**:
   точка уровня не занимает вход ПЛК. Датчик работает на прибор по своей линии
   (`Rxd1`/`Txd1`/`+12В/1`/`Gnd1` для первого канала, `Rxd2`/`Txd2`/`+12В/2`/`Gnd2`
   для второго), а на ПЛК уходит одна линия RS-485 на прибор — четыре на панель.
   Когда появится раздел загрузки ПЛК, эти четыре линии надо считать по приборам,
   а не по точкам.
2. **Приборов в выгрузке три, а не четыре.** Заказчик подтвердил исполнение на
   четыре прибора (`LV1`…`LV4`), в библиотеке их четыре. Разъём четвёртого
   прибора (`XP10`) в схеме отсутствует — обозначение продолжает ряд `XP1`, `XP4`,
   `XP7` и требует подтверждения.
3. **Тип датчика уровня** панелью не закреплён: в комплекте прибора идёт жгут
   для подключения датчиков, а какие именно преобразователи ставятся, задаётся
   проектом.
4. **Спецификации панели нет** — состав монтажной плиты (розетки РД-47,
   автоматы, клеммы) описан в `docs/Рабочая документация — данные панелей.md`
   по листу компоновки.

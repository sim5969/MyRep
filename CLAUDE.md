# CLAUDE.md — НТ53 «Конфигуратор секций АСУ ТП»

Проект ООО «Нефтяные технологии». Весь контекст, правила и журнал ведутся в пакете `AI/` —
этот файл лишь точка входа, которую Claude Code подгружает автоматически.

## Прочитать при старте сессии

1. `AI/README.md` — обзор пакета и рабочих зон
2. `AI/AI_RULES.md` — обязательные правила совместной работы
3. `AI/AI_HANDOFF.md` — текущее состояние («передача смены»)
4. `AI/PROJECT_MANIFEST.md` — реестр файлов проекта
5. `AI/DECISIONS.md` — устойчивые решения
6. `README.md` (в корне) — техническое описание приложения: геометрия, выгрузки, как добавить модуль

## Проект

- **Шифр:** НТ53
- **Продукт:** веб-конфигуратор внешнего вида секций АСУ ТП — сборка фасада секции из типовых
  вставных модулей, выгрузка PDF А3, DXF, таблицы надписей и спецификации XLSX.
- **Тип:** программный проект (Vite + TypeScript + React). Основной результат — **код приложения**
  и библиотека модулей `src/library/*.json`.
- **Стадия:** этап 1 завершён, этап 2 (выгрузки) частично — состояние в `README.md` и `AI/AI_HANDOFF.md`.
- **Исполнитель:** ООО «Нефтяные технологии» (реквизиты — `AI/company/Реквизиты_ООО_НТ.md`)

## Ключевые правила (кратко; полностью — в `AI/AI_RULES.md`)

- Работать только внутри папки проекта; язык кода-комментариев и документации — русский.
- **Рабочий каталог — локальная Git-копия** (`C:\NT\Шкафы АСУТП НТ53`); Claude Code и dev-сервер
  запускать здесь. Bash локально стабилен.
- **Выгрузка EPLAN и фотографии панелей (папка `Модули`) — на Synology `P:`, вне Git.** Скрипты
  разбора DXF (`rd-facade`, `rd-spec`, `check-photos`) берут её из `NT_ASUTP_DATA`
  (по умолчанию `P:\Projects\Шкафы АСУТП НТ53`).
- Библиотека модулей **генерируется** (`scripts/gen-library.mjs`); править генератор, затем
  `npm run gen:library && npm run check`. Не править `src/library/*.json` вручную.
- Фирменная рамка PDF и логотип — из шаблона AI-пакета ООО «НТ» (`npm run gen:frame`), не
  вычерчивать по ГОСТ заново.
- Выгрузки и документы выпускаются от имени ООО «НТ»; реквизиты и оформление — только из `AI/company/`.

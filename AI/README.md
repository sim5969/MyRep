# AI project package — ООО «Нефтяные технологии»

Этот каталог — стартовая точка для работы людей и AI-ассистентов с проектной папкой через
VS Code и похожие инструменты. Пакет оформлен по стандарту ООО «Нефтяные технологии» (ООО «НТ»).

Проект: **НТ53. Конфигуратор секций АСУ ТП** — веб-приложение для сборки фасада секции АСУ ТП
из типовых вставных модулей и выгрузки комплекта документов (PDF А3 в фирменной рамке, DXF вида
на фасад, таблица надписей, спецификация XLSX). В отличие от документационных проектов ООО «НТ»,
здесь **основной результат — код приложения**, поэтому весь исходный код ведётся в Git.

Пакет не заменяет техническое описание приложения (корневой `README.md`). Он описывает, где что
лежит, какие правила обязательны, что уже сделано и как безопасно продолжать работу нескольким
участникам.

## С чего начинать

1. Прочитать `AI_PROJECT_CONTEXT.md` — направления работ и рабочие файлы.
2. Прочитать `AI_RULES.md` — обязательные правила для всех задач.
3. Проверить актуальное состояние в `AI_HANDOFF.md`.
4. Для устройства приложения — корневой `README.md` (геометрия, выгрузки, как добавить модуль).
5. Перед массовыми изменениями свериться с `DECISIONS.md`.

## Канонические рабочие зоны

Модель v2.0 (подробно — `AI/AI_COLLAB.md`): текст и код — в **локальной Git-копии**
(`C:\NT\Шкафы АСУТП НТ53`), бинарники и исходные данные — на **Synology** (`\\NT1`, диск `P:`).

В локальной Git-копии (версионируется в Git):

- Код приложения: `src/` (типы, геометрия, компоненты, выгрузки), `scripts/` (генераторы и
  проверки), `tests/` (эталоны подбора), `docs/` (документация модели данных, каналы, замечания).
- Библиотека модулей: `src/library/*.json` (генерируется `scripts/gen-library.mjs`).
- Общий AI-контекст проекта: `AI/`; реквизиты и оформление ООО «НТ»: `AI/company/`.
- Точка входа `CLAUDE.md`, конфигурация сборки (`package.json`, `tsconfig.json`, `vite.config.ts`).

- **Фотографии панелей** — `Модули/*.jpg` и `Модули/README.md` (сверяются `check-photos`); в Git
  с 14.10.2026.

На Synology (`P:`, в Git не ведётся):

- **Выгрузка EPLAN** — `Модули/Макросы V25.02 (Platform_2026)/` (рабочая документация панелей в
  DXF, ~77 МБ). Источник для ручной сборки панелей и скриптов `rd-facade`/`rd-spec`. Не изменять.
  Локально кладётся в ту же папку `Модули` клона — `.gitignore` её отсекает.
- Сборка `dist/` с файлом запуска и книга `Модули НТ53.xlsx`.
- Крупные исходные изображения в корне проекта.

Корень бинарников задаётся переменной `NT_ASUTP_DATA` (по умолчанию `P:\Projects\Шкафы АСУТП НТ53`)
или файлом `AI/scripts/local.config` (в `.gitignore`).

## Организация-исполнитель

Все выпускаемые документы и выгрузки (PDF со штампом, спецификации) оформляются от имени
**ООО «Нефтяные технологии»**. Реквизиты, логотип и фирменная рамка — из `AI/company/` и шаблона
AI-пакета ООО «НТ». Не вводить реквизиты вручную из памяти.

## Важный принцип

Если правило или решение стало постоянным, его нужно вынести из чата в файл этого каталога
(`AI_RULES.md`, `DECISIONS.md` или профильный контекст в `context/`). Чат не считается надёжным
единственным источником правил.

## Инфраструктура и репозиторий

- **2026-08-26. Проект переведён на модель ООО «НТ» v2.0** (Synology + централизованный Git Gitea).
  Репозиторий — `NT/asutp-nt53` (`http://NT1:3000`), приватный, владелец — организация `NT`.
- **2026-08-26. В Git — только код и текст.** Весь исходный код приложения (`src/`, `scripts/`,
  `tests/`, `docs/`), библиотека `src/library/*.json`, пакет `AI/`, `CLAUDE.md`, конфигурация сборки.
  Состав обеспечивает корневой `.gitignore` (whitelist).
- **2026-08-26. Выгрузка EPLAN и фотографии панелей — на Synology `P:`, вне Git.** Папка `Модули`
  целиком (`Макросы V25.02 (…)\` — 77 МБ DXF, и `*.jpg`) остаётся на `P:` как входные данные
  (аналог `Исходники/`). Причина: бинарь большой и периодически перевыгружается — в Git раздувал бы
  историю. Git LFS **не используется** (стандарт компании — бинарники не в Git).
- **2026-08-26. Путь к бинарникам — через `NT_ASUTP_DATA`** (по умолчанию
  `P:\Projects\Шкафы АСУТП НТ53`) или `AI/scripts/local.config`. Резолвинг вынесен в
  `scripts/data-root.mjs` (`DATA_ROOT`, `MODULES_DIR`). `check-photos.mjs` переведён на него и
  корректно пропускает сверку (exit 0), если папка `Модули` недоступна. `rd-facade`/`rd-spec`
  берут путь к DXF из аргумента — их не трогали.

## Приложение (файлы проекта)

- **2026-10-13. Сохранение проекта — только через системное окно «Сохранить как»** (File System
  Access API в Chrome/Edge; в Firefox — обычная загрузка браузера). Диалог открывается в папке
  текущего файла и предлагает его имя; браузер запоминает папку под ключом `nt53-project`.
  Причина: прежняя «тихая» загрузка складывала «Новый проект (N).json» в «Загрузки» — файл было
  не найти и не отличить от соседних.
- **2026-10-13. Имя файла и наименование проекта — разные вещи.** Имя открытого файла показывается
  в строке конфигуратора рядом с наименованием и в заголовке вкладки (`store.file`, в JSON не
  пишется, после перезагрузки восстанавливается из `localStorage`). Наименование проекта (графа
  штампа «Наименование объекта») при открытии и сохранении берётся из имени файла только пока
  стоит «Новый проект» (`nameAfterFile` в `src/lib/project.ts`); заданное явно наименование файл
  не меняет — проекты от `npm run plan` с `--out="проект.json"` сохраняют длинное наименование.
- **2026-10-13. Сборка выкладывается на Synology в `P:\Projects\Шкафы АСУТП НТ53\dist`**
  (`npm run deploy`, путь — `NT_ASUTP_DATA`), рядом «Запуск конфигуратора.bat». Web Station на NT1
  не настроен, папка `web` пуста — статический хостинг не используется. Сборка с `base: './'`:
  относительные пути, чтобы работала из подпапки. Открывать через bat (локальный сервер Python на
  `localhost:8653`): со схемы `file:` Chrome/Edge не грузят модули, а окно «Сохранить как»
  (File System Access API) доступно только на `localhost`/`https`.

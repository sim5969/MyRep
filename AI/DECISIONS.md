## Инфраструктура и репозиторий

- **2026-08-26. Проект переведён на модель ООО «НТ» v2.0** (Synology + централизованный Git Gitea).
  Репозиторий — `NT/asutp-nt53` (`http://NT1:3000`), приватный, владелец — организация `NT`.
- **2026-08-26. В Git — только код и текст.** Весь исходный код приложения (`src/`, `scripts/`,
  `tests/`, `docs/`), библиотека `src/library/*.json`, пакет `AI/`, `CLAUDE.md`, конфигурация сборки.
  Состав обеспечивает корневой `.gitignore` (whitelist).
- **2026-08-26. Выгрузка EPLAN и фотографии панелей — на Synology `P:`, вне Git.** Папка `Модули`
  целиком (`Макросы V25.02 (…)\` — 77 МБ DXF, и `*.jpg`) остаётся на `P:` как входные данные
  (аналог `Исходники/`). Причина: бинарь большой и периодически перевыгружается — в Git раздувал бы
  историю. Git LFS **не используется** (стандарт компании — бинарники не в Git).
- **2026-08-26. Путь к бинарникам — через `NT_ASUTP_DATA`** (по умолчанию
  `P:\Projects\Шкафы АСУТП НТ53`) или `AI/scripts/local.config`. Перевод скриптов разбора DXF на
  эту переменную — запланирован (см. `AI_HANDOFF.md`), по факту выполнения дополнить эту запись.

## Библиотека модулей

- **2026-08-26. Модуль 48 — «ИВК „Зодиак", 2 шт.»** добавлен по дополнительной выгрузке EPLAN
  (`+48`). Два измерительно-вычислительных комплекса 96×96 в монтажных рамках. Геометрия снята с
  листа компоновки (центры 185 мм, рамка ≈130×131); фасадного листа/фото нет — размеры
  приблизительные. Каналы и допущения — `docs/каналы/48.md`.
- **2026-08-26. Модуль 49 — «Блок программного управления (БПУ)»** добавлен по выгрузке `+49`.
  Управление отбором пробы (электромагнит, обогрев, концевик), пуск «От ИВК1». В выгрузке БПУ дан
  растровым фото без артикула — габарит (≈206×194) снят по размещению фото на панели, требует
  уточнения. Лампа VD1 «Проба» отнесена к монтажной плите (не на фасад). Каналы — `docs/каналы/49.md`.
- Соглашение (действует ранее): `src/library/*.json` не правятся вручную — только через
  `scripts/gen-library.mjs` и `npm run gen:library`; каналы — в `docs/каналы/<код>.md`.

Ориентир по файлам проекта НТ53. Подробное техническое описание — корневой `README.md`.

| Файл | Назначение |

| `AI/README.md` | обзор пакета и рабочих зон |
| `AI/AI_PROJECT_CONTEXT.md` | контекст проекта и направления работ |
| `AI/AI_RULES.md` | обязательные правила совместной работы |
| `AI/AI_WORKFLOW.md` | порядок работы с AI |

## Код приложения (в Git)

| Путь | Назначение |
|---|---|
| `src/` | приложение: типы, геометрия, состояние, компоненты, выгрузки (`export/`) |
| `src/library/*.json` | описания панелей — **генерируются** `scripts/gen-library.mjs` |
| `scripts/gen-library.mjs` | генератор библиотеки модулей |
| `scripts/kinds.mjs`, `scripts/plan.mjs`, `scripts/export.mjs` | правило «объект ТЗ → модуль», компоновка, выгрузка из CLI |
| `scripts/rd-facade.mjs`, `scripts/rd-spec.mjs` | разбор выгрузки EPLAN (DXF) в геометрию/спецификацию |
| `scripts/check-*.mjs` | проверки: геометрия, фото, регрессия подбора, DXF, PDF |
| `docs/` | модель данных модуля, каналы подключения (`каналы/<код>.md`), замечания к EPLAN |
| `tests/plan/<случай>/` | эталонные задания и проекты для `npm run check:plan` |
| корневой `README.md` | техническое описание: геометрия, выгрузки, как добавить модуль |

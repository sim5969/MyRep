# Компоновщик силовых шкафов — Фаза 1

Клиентское приложение предварительной компоновки силовых шкафов (ПЧ VEDA VF-101 +
автоматы/контакторы Chint, каркас 600×600×2000). Один самодостаточный файл, без сервера.

## Как пользоваться (локально, «плагин»)

Открыть **`index.html`** двойным кликом в любом браузере. Интернет не нужен
(шрифты подгружаются при наличии сети, без неё берётся системный).

- Слева — список насосов: тег, наименование, мощность (число с подсказками), количество.
  Кнопка **«Загрузить файл»** (или перетащить файл на панель) импортирует список из
  `.xlsx` (шаблон «Список насосов (вход).xlsx»), `.csv` или `.txt`. Колонки определяются
  по шапке (Тег / Наименование / Мощность / Кол-во); мощность «между строк» округляется
  вверх при подборе. Чтение xlsx — нативное (без внешних библиотек).
- Справа — три вкладки:
  - **Шкафы и раскладка** — карточки шкафов с 2D-раскладкой на каркасе (ПЧ сверху,
    панели управления с автоматом QF + контактором KM снизу, размерная цепь от поз.1,
    контроль зазора снизу ≥ 300 мм);
  - **Подбор по насосам** — ПЧ → автомат → контактор по каждому насосу;
  - **Сводная ведомость** — агрегированная закупка.
- **Экспорт CSV** — выгрузка всех трёх таблиц (открывается в Excel).
- **Печать / PDF** — печать раскладки и таблиц (кнопка-принтер вверху).
- Тумблер темы (солнце) — светлая/тёмная, запоминается.

## Как разместить на сайте

Скопировать `index.html` на любой статический хостинг (или во внутренний портал) —
внешних зависимостей, кроме Google Fonts, нет. Работает как есть.

## Обновление каталога

Данные подбора и правила компоновки зашиты в `index.html` при сборке из
`../Панели с ПЧ/catalog.json`. После правки каталога пересобрать:

```
python build.py
```

Скрипт внедряет свежий `catalog.json` в `_template.html` → `index.html`.
Логику раскладки и разметку править в `_template.html`.

## Состав

| Файл | Назначение |
|------|-----------|
| `index.html` | готовое приложение (продукт) |
| `_template.html` | шаблон с плейсхолдером `__CATALOG_JSON__` |
| `build.py` | пересборка index.html из каталога |
